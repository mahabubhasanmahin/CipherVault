How this works

  • AES-GCM and RSA-OAEP run through your browser's native Web Crypto API — the key never touches our servers.
  • ChaCha20-Poly1305 isn't in Web Crypto yet, so that path uses libsodium.js in-browser.
  • Only ciphertext and metadata are stored in the vault. Losing your passphrase means losing the data — there's no recovery.
